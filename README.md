## About Me

I'm a CSE undergrad who ended up specializing in **shipping ambitious, visually-loaded builds against absurd deadlines** — hackathons, case competitions, national-level challenges. I work across the whole stack: frontend that leans hard into motion, shaders and dark/cyberpunk UI, and backend/systems work spanning ML pipelines, API security, load testing and CI/CD.

- 🔭 Currently juggling a drone-swarm ML "brain," a grid-demand forecasting system, and a city-scale CCTV analytics platform
- 🧠 Comfortable moving between ML/data problems and low-level systems concerns (security, infra, real-time pipelines)
- 🎨 Have a soft spot for interfaces that feel over-engineered on purpose — glassmorphism, custom GLSL shaders, animated 3D scenes
- ⚡ Optimize for "working and impressive" over "minimal and safe," especially on the clock
- 📫 Reach me at **kartikeyyyyyaaa@gmail.com**
